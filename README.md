# Transpose

Rebuild any flow in your design system, including the states the screenshots don't show.

> Work in progress. See [the spec](.sdd/specs/000-mvp.md) for the plan.

## Run it locally

1. Install Node 24 or later and pnpm 12 or later.
2. Run `pnpm install`.
3. Run `pnpm check`.
